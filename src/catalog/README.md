Catálogo público do Cell Griot, importado sem executar JavaScript remoto.

A paleta contém 36 Cells (13 Artcraft) e conserva 16 aliases de workflows anteriores. Os SVG são os símbolos originais do site e as geometrias Lucide usadas pelos conectores. Ficam incluídos na app para funcionar sem pedidos externos de ícones. Os logótipos dos modelos seguem o fornecedor configurado.

Atualização: node scripts/sync-cell-catalog.cjs. O script só consulta ficheiros públicos de https://cell-griot.pages.dev e escreve nesta app. A origem e o hash estão em cells.ts. Nunca altera o site, o backend ou permissões.

Os conectores públicos e privados do espaço são consultados pela API existente, sob a sessão e as permissões atuais. A presença no catálogo não concede autorização de execução.
